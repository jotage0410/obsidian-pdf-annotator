# PDF Annotator for Obsidian

Annotate PDFs with stylus support (S-Pen, Apple Pencil), pressure sensitivity, palm rejection, text highlighting, and persistent annotations.

## Features

- Free drawing with pressure sensitivity via perfect-freehand
- Palm rejection for tablet use (S-Pen / Apple Pencil)
- Text highlighting from PDF text layer
- Highlighter tool with adjustable colors
- Eraser with undo/redo support
- Annotations persisted as JSON sidecar files
- Lazy PDF rendering for large documents
- Hi-DPI support

## Installation

1. Copy the plugin folder to `.obsidian/plugins/pdf-annotator/`
2. Enable the plugin in Obsidian Settings > Community Plugins
3. Open any PDF file in your vault

## Development

```bash
npm install
npm run dev    # watch mode
npm run build  # production build
```
